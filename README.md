# Distill Scientific Writing Method

A Codex skill that turns a bounded corpus of full-text scientific papers and optional author commentary into an evidence-backed editorial decision playbook.

Unlike a style imitator, this skill audits writing ownership, separates published behaviour from stated philosophy, searches for counterexamples, controls for journal and study constraints, and assigns confidence to every extracted rule.

## What it produces

- a source and authorship-tier inventory;
- one evidence dossier per paper and commentary source;
- nine-dimensional rhetorical analysis;
- commentary-hypothesis tests;
- a rule-evidence matrix with counterexamples and confounders; and
- a portable author writing playbook.

## Install

Copy `skills/distill-scientific-writing-method` into your Codex skills directory and refresh Codex.

## Use

```text
Use $distill-scientific-writing-method to analyse every full-text paper in ./corpus and the optional supervision transcript separately. Distill the author's editorial decision method without imitating distinctive prose or inspecting my manuscripts.
```

## Privacy and copyright

The repository contains only the extraction workflow. It contains no target-author papers, transcripts, derived author rules, or manuscript material.
